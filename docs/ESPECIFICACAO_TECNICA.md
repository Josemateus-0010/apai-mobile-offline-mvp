# Especificação Técnica do MVP - APAI Mobile

## 1. Arquitetura Local (Offline-First)
* **Framework:** Flutter (Dart)
* **Banco de Dados Local:** SQLite (sqflite)
* **Mecanismo de Persistência:** Cache de dados local para operação sem conectividade com a internet.

## 2. Requisitos Principais
* Registro de lotes apícolas e manutenções de colmeias.
* Agendamento offline de equipamentos comunitários.
* Sincronização automática quando detectada conexão ativa.
